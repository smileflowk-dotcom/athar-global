# Moisture-Swing Discovery Engine — Current Hypothesis

## Working hypothesis

The best moisture-swing sorbent will emerge from interactions among material architecture, functional chemistry, counter-ion, water response, and operating conditions; it cannot be discovered reliably by counter-ion screening alone.

## Current implementation hypothesis

Use public experimental data to learn the response surface and uncertainty first, then reserve atomistic calculations for shortlisted, information-rich candidates.

## Priority hypothesis

The phosphate family is an evidence-backed priority search region. Current priority variants are HPO4^2-, PO4^3-, and P2O7^4-, but performance is expected to depend on resin/backbone, functional-group or ammonium type, pore architecture, hydration response, and operating conditions.

This is a prioritization hypothesis, not a claim that phosphate is universally best.

## Immediate validation target

Do not restart discovery from zero.

Build a phosphate-centered candidate matrix from the evidence already accumulated, with carbonate as the principal control and only justified non-phosphate comparators.

Then use the public MSA-ML data/modeling methodology selectively to answer:

1. which resin × functional-group × pore × phosphate combinations are supported by existing data;
2. where predictive uncertainty is highest;
3. which combinations are out-of-distribution rather than merely high-scoring interpolations;
4. which 3-10 combinations are both information-rich and experimentally feasible;
5. whether any proposed combination survives targeted atomistic and independent-method checks.

ALCHEMI remains downstream and is only used on shortlisted combinations.

## Current scientific status

No new material candidate is validated.

V1-V6 are retained as infrastructure/method-learning evidence, not as final discovery evidence.
