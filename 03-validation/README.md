# 03 — Validation

This folder stores experimental evidence and measurements.

Use these labels:

- `TEST` — what was tested and under which conditions.
- `EXPECTED` — the result defined before the test.
- `ACTUAL` — what the experiment observed.
- `RESULT: PASS / FAIL / INCONCLUSIVE` — the evidence-based outcome.
- `NEXT` — the next action justified by the result.
