# SCALE PROTOCOL

Central question: can we reduce a very large traceable candidate/configuration space to a small, diverse, evidence-backed set worth experimental testing?

## Gates

### 10K -> 1K
Use only cheap operations:
- chemistry sanity
- provenance completeness
- feature-range checks
- ML prediction
- uncertainty
- OOD
- hard feasibility exclusions

Never rank purely by predicted Qe.

### 1K -> 100
Preserve chemical diversity.
Include:
- uncertainty-adjusted score
- OOD penalty
- family quotas / clustering
- matched controls when possible
- commercial/material plausibility

### 100 -> 20
Add:
- targeted literature novelty
- public availability/manufacturability evidence
- evidence quality score
- falsification checks

### 20 -> 5
Run expensive methods in parallel:
- NVIDIA ALCHEMI/AIMNet2 local screening
- multiple hydration levels / seeds
- independent computational cross-check
- reject non-converged results

### 5 -> 1-3 LAB
Require multiple independent positive signals.
Prepare a falsifiable lab test packet.
No discovery claim before measurement.

## Decision rule
Every expensive action must answer: "What uncertainty does this reduce?"
If none, skip it.
